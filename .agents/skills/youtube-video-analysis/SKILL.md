# Video analysis

Use the installed `video-analysis` plugin's skill with the caller's question and working directory. Resolve `SKILL` to that plugin's `skills/video-analysis` directory for its helpers and references. In Sunrei, the [plugin locator](../../../.claude/scripts/youtube/video_analysis_plugin.py) prints this path.
For a Sunrei ingest, follow [youtube-to-sunrei](../youtube-to-sunrei/SKILL.md).
